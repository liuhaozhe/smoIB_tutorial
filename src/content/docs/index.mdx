<div lang="en">

Here, we present a benchmarking framework for spatial domain identification, comparing 14 representative methods across 15 datasets spanning RNA–ATAC and RNA–protein modalities, with performance summarized across 20 random seeds. The framework evaluates agreement with reference annotations where available, embedding structure, neighborhood preservation, and spatial coherence.

This tutorial outlines how to run and compare spatial multi-omics integration methods. Start with one dataset to learn how to prepare the inputs, run a method, and check its output. Then extend the workflow to reproduce comparisons across methods and datasets.

:::note[Tutorial status]
These guidelines currently describe the workflow and the checklist for each step, as well as links to papers, code, and datasets, environments and sample commands for reproducing the results.
:::

## Start here

For your first analysis, work through the guides in order.

1. Check software versions, dependencies, and hardware requirements in [Environment setup](guides/installation/).
2. Obtain the data and check the modalities, sample identifiers, and spatial coordinates with the [Data preparation guide](guides/data-preparation/).
3. Follow the [Quick start](guides/getting-started/) to see what a minimal run involves and how to tell whether it succeeded.
4. Follow one dataset from input files to result figures in [Single-dataset analysis](tutorials/single-dataset/).
5. Extend the analysis to multiple methods, datasets, and repeated runs in [Reproducing the benchmark](tutorials/benchmark-reproduction/).

## What to record for each run

Record the data and code versions, software environment, configuration, and random seeds. Keep these records with the raw outputs and evaluation results so you can trace each figure back to the run that produced it. The examples will include file formats, parameters, and expected outputs alongside the code.
